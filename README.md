One sentence about the best meal I ever had: rendang at a warung in Yogyakarta,
coconut gravy clinging to warm rice, cinnamon smoke in the air, and a plate
scraped clean like it owed me money.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes exactly one sentence (154 characters, one line) to `<output dir>/entry.txt`,
then re-reads the file from disk to verify the on-disk content matches the
intended sentence plus one trailing newline.
